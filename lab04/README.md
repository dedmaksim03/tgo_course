# Лабораторная 4

## Что сделано

Выполнен пункт 1: подготовка данных `mteb/GeoreviewClassification`.
Общая логика находится в `data.py` и используется в `train.ipynb` и `run.py`.
С seed=42 выбраны 5000 обучающих отзывов (по 1000 на класс) и пять
постоянных few-shot примеров из validation (по одному на класс).
Тест — первые 1000 отзывов без перемешивания, в `--fast` — первые 24.
Исходный `label` (0–4) сохранён, добавлено поле `stars` (1–5).

В `train.ipynb` добавлены загрузка `Qwen/Qwen3-0.6B` и составление
промптов zero-shot и few-shot для одного тестового отзыва.
Системная инструкция и функции составления сообщений находятся в `prompts.py`.
Few-shot использует пять пар реплик из validation, шаблон Qwen применяется
с `enable_thinking=False`.
В `inference.py` добавлены жадная генерация (до трёх новых токенов)
и разбор оценки 1–5. Ответ без допустимой цифры возвращает `None`
и учитывается в `invalid`. В ноутбуке оба режима проверяются на одном отзыве.

Запуск из корня репозитория:

```bash
python lab04/run.py
python lab04/run.py --fast
```

Откройте `train.ipynb` и выполните все ячейки; выводы уже сохранены.

Проверены баланс обучения, воспроизводимость выборок и исходный порядок теста.
Данные кэшируются вне сдаваемых файлов и в Git не добавляются.

На первом тестовом отзыве с правильной оценкой 3 модель ответила 4
в zero-shot и 2 в few-shot; оба ответа разобраны успешно (`invalid=0`).
Один пример не позволяет сравнивать качество режимов на всей выборке.
