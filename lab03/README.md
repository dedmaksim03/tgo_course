# Лабораторная 3

## Что сделано

По умолчанию используется CPU: `python lab03/run.py`. Для запуска на видеокарте NVIDIA с поддержкой CUDA: `python lab03/run.py --device cuda`. Флаг совместим с `--fast`. Модель и входные тензоры размещаются на выбранном устройстве; оно записывается в `tiny_config.json`.

Подготовлены BPE-потоки train и val с разделением по словам 90/10. Собран декодер на PyTorch: обучаемые эмбеддинги токенов и позиций, четыре блока ширины 128, по четыре головы внимания размерности 32. Внимание реализовано самостоятельно через Q/K/V, масштабирование, причинную маску, softmax и взвешенную сумму V.

В каждом блоке используются LayerNorm перед вниманием и FFN, две остаточные связи и полносвязная сеть `128 → 512 → 128` с GELU. После четырех блоков стоят финальная LayerNorm и линейный слой в словарь. Архитектура и точное число параметров сохраняются в `artifacts/tiny_config.json`.

Реализован цикл обучения AdamW с `lr=0.001` и seed 42. Полный режим выполняет 2000 шагов при батче 32, `--fast` — 200 шагов при батче 16. В `train_curve.csv` записываются ошибки до обучения (шаг 0), затем каждые 100 или 25 шагов: средний train loss за отрезок и val loss на одних и тех же 20 проверочных окнах. После завершения параметры запуска, размеры потоков и время обучения добавляются в `tiny_config.json`. Веса на диск не записываются.

## Что получилось

Для словаря из 1516 токенов число параметров модели — **1 199 340**. Контекст — 128 токенов, ширина — 128, число блоков — 4, число голов в каждом — 4, ширина FFN — 512. Эти значения записаны скриптом в `tiny_config.json`; веса модели не сохраняются.

Модель принимает ID формы `[batch, length]` и возвращает логиты `[batch, length, vocab_size]`. Проверены запрет влияния будущих токенов на предыдущие, независимость весов блоков и прохождение градиентов. При нулевых поправках остаточные связи сохраняют вход блока.
